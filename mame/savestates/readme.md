These are save states for use with certain arcade games, either to be loaded automatically, or to be downloaded and loaded at the game start

Crystal Castles:
Competitive settings enabled with freeplay. Default settings of 3 lives, can gain extra lives and medium difficulty enabled.

Defender:
Bypasses the test menu on first boot.

Mortal Kombat 1:
Competitive settings enabled with freeplay. Default settings of medium difficulty enabled.

Street Fighter 2 - Rainbow Edition:
Start at title screen with a credit already available.

UMK3:
Start at test menu (allows configuring game options such as difficulty).
